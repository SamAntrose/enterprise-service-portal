SECTION 3

🔧 Your Backend Work — Talking Points for Mam

Use these points when explaining your specific contributions to the project:

🗣️ Point 1: "I built the Python FastAPI backend server"

  • "I developed the backend server using Python FastAPI framework with Uvicorn as the ASGI server"
  • "The server exposes REST API endpoints like /analyze for AI classification and /tickets for CRUD operations"
  • "I chose FastAPI because it supports async operations and auto-generates API documentation"

🗣️ Point 2: "I integrated Hugging Face AI models for ticket classification"

  • "I loaded two pre-trained NLP models — DistilBERT for category classification and RoBERTa for sentiment/urgency analysis"
  • "When a user types a ticket description, my backend analyzes the text and returns the predicted category (Hardware/Software/Facilities/Network) and priority level (P1–P4)"
  • "I also built a heuristic fallback classifier so the frontend works even without the Python server"

🗣️ Point 3: "I designed the PostgreSQL database schema"

  • "I designed the relational database with tables for users, tickets, assets, kb_articles, change_requests, and audit_logs"
  • "I used SQLAlchemy ORM to map Python objects to database tables — so we write Python code, not raw SQL"
  • "I set up foreign key relationships — for example, each ticket links to a user (creator) and optionally to an asset"

🗣️ Point 4: "I implemented the authentication and security system"

  • "I built the multi-role login system with 3 roles — Admin, Employee, and Technician — each seeing different dashboards"
  • "I integrated FormSubmit.co REST API to send real 2FA OTP codes to the user's Gmail inbox"
  • "I implemented brute-force protection that locks accounts for 15 minutes after 5 failed login attempts"

🗣️ Point 5: "I built the SLA timer engine and business logic"

  • "I created the SLA countdown engine that assigns different time limits based on priority — P1 gets 2 hours, P2 gets 8 hours, P3 gets 24 hours"
  • "I wrote the domain filtering algorithm — hardware technicians only see hardware tickets, software technicians only see software tickets"
  • "I built the ticket data model with auto-generated codes like TICK-9F82A1 and automatic vendor routing"

🗣️ Point 6: "I integrated the Emergency SOS dual-alert system"

  • "When SOS is triggered, my code does two things simultaneously — opens the phone dialer using tel: protocol AND sends an alert email to the admin"
  • "I used the FormSubmit.co API with fetch() to send the email containing the caller's name, phone number, and timestamp"
  • "This dual-channel approach ensures the admin is alerted even if the phone call doesn't connect"
